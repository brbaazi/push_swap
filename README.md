# push_swap 🔄

**push_swap** is a 42 School project focused on **sorting algorithms and data structures**.

The goal is to sort a stack of numbers using a limited set of operations with the smallest possible number of moves.

## 🎯 Goal

Sort the numbers in stack `a` using two stacks:

* Stack `a`
* Stack `b`

The program must use only the allowed operations.

## ⚙️ Operations

```text
sa  → swap a
sb  → swap b
ss  → swap both
pa  → push to a
pb  → push to b
ra  → rotate a
rb  → rotate b
rr  → rotate both
rra → reverse rotate a
rrb → reverse rotate b
rrr → reverse rotate both
```

## 🚀 Usage

Compile:

```bash
make
```

Run:

```bash
./push_swap 4 67 3 87 23
```

The program outputs the operations needed to sort the numbers.
